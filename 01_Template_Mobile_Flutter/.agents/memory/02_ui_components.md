# Memoria de Dominio 02: Componentes UI & Diseño Adaptativo

> Última validación: 2026-09-02 | Estado: Plantilla Oficial Enterprise Hub  
> Invariantes de componentes de interfaz, diseño responsive y jerarquía visual.

---

## 📋 Reglas Preventivas de Dominio

1. **Construcción Determinista:** Preferir widgets pequeños y reutilizables con constructores const.
2. **Diseño Responsive:** Manejo estricto de desbordamientos con LayoutBuilder, MediaQuery y widgets flexibles (Expanded, Flexible).
3. **Accesibilidad y Semántica:** Asegurar contraste óptico adecuado y etiquetas accesibles en controles interactivos.
