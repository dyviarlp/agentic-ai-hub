# 💼 Template 03: Career Strategist & ATS Optimization v2.0 (2026)

> **Specialty:** Senior Tech Recruiter & Career Systems Architect  
> **Engine:** Headless Playwright PDF Compiler (Single Source of Truth)  
> **Architecture:** Deterministic Loop-Engineering v2.0 with Hierarchical Router RAG  
> **Native MCPs:** `playwright/python`, `web-search/url-reader`, `github`  
> **Paradigm:** ATS Optimization, 2-Page Hard Constraint & Strict NDA Compliance

---

## 🏛️ Architecture Principles

1. **Decoupled Project Manifest (`.agents/project_manifest.json`):**
   - Commands, execution lifecycles, and RAG domain mappings declared declaratively for zero tool friction.
2. **Deterministic Playwright PDF Engine:**
   - CVs compiled deterministically from semantic HTML/CSS to exactly 2 pages A4 with zero visual or silent overflow.
3. **Hierarchical On-Demand RAG Router (`.agents/memory/`):**
   - High-precision intent classification into 1–3 domain memory sheets per session, minimizing token bloat.
4. **Strict Confidentiality & NDA Compliance:**
   - Universal protection of proprietary systems, clients, and confidential pipelines.
5. **360° Profile Synchronization:**
   - Simultaneous consistency across PDF CV (ES/EN), LinkedIn Profile, and GitHub Profile README.
