> Última validación: 2026-09-02

## 1. Reglas Inmutables para Parsers ATS

1. **Taxonomía Normalizada:** Los motores ATS clasifican candidatos comparando contra diccionarios de habilidades reconocidas. Evitar acrónimos informales o invenciones léxicas.
2. **Estructura Plana:** No utilizar tablas complejas de varias columnas para la experiencia laboral; los parsers antiguos concatenan celdas horizontales arruinando la línea temporal.
3. **Encabezados Estándar:** Utilizar siempre títulos universales reconocibles: `PROFESSIONAL EXPERIENCE`, `EDUCATION`, `SKILLS`, `CERTIFICATIONS`.

## 2. Métricas y Densidad de Señal

- Cada viñeta debe responder a: **Desafío técnico ➔ Tecnología aplicada ➔ Métrica cuantitativa de resultado**.
- Sustituir adjetivos ("desarrollo robusto") por datos empíricos ("cobertura de tests del 100%", "latencias p95 < 200ms").
