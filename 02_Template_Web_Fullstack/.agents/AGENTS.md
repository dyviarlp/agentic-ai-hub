> **Paradigma:** Estética de Autor (Anti-Plantilla IA), Core Web Vitals y Rendimiento Extremo.

---

## 1. Reglas Inmutables de Ingeniería Web

1. **Estética y Tipografía Curada (UI/UX Pro Max):**
   - Prohibido interfaces genéricas de IA. Uso de tipografías Google Fonts (Inter, Outfit, Roboto), paletas armónicas HSL y glassmorphism sutil.
2. **Estándares Web 2026 & Core Web Vitals:**
   - HTML5 semántico, CSS moderno (container queries, selector `:has()`, subgrid, view transitions).
   - LCP < 2.0s, INP < 200ms, CLS < 0.1.
3. **Contratos TypeScript Estrictos:** Todo componente y endpoint en Vercel Serverless (`api/`) debe ser TypeScript tipado, con validación de payload y cabeceras CORS seguras.
4. **Accesibilidad (a11y):** Cumplimiento estricto WCAG AA, contraste accesible, navegación por teclado y tags meta/SEO completos.
