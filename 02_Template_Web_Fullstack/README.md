## 🏛️ Architecture Principles

1. **Author-Grade UI/UX (Anti-Generic AI):**
   - Curated typography (Inter, Outfit, Roboto), semantic HSL color scales, subtle glassmorphism and micro-interactions.
2. **Core Web Vitals Enforcement:**
   - LCP < 2.0s, INP < 200ms, CLS < 0.1.
   - Semantic HTML5, container queries, modern CSS `:has()`, view transitions.
3. **Strict TypeScript Serverless Contracts:**
   - Endpoints in Vercel (`api/`) with runtime validation, typed interfaces, and secure CORS headers.
4. **Accessibility (a11y):**
   - Strict WCAG AA compliance, visible keyboard focus indicators, and complete SEO metadata.
